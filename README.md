# target2lenustorm

ESSnuSB+ Simulation Studies

## Structure

- **fluka0** initial FLUKA simulation code for target and decay pipe
- **pprod** files to generate particle production out of the target. It stores the files containing selected spieces of particles (typically only mesons) at the exit of the target volume
- **raytrace_cpp** tracking code developed for LAGUNA-LBNO CN2PY design studies
- **lenustorm** fluka simulation for the tt2nustorm line
